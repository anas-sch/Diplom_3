## Дипломный проект. Задание 3: веб-приложение

### Автотесты для проверки пользовательского интерфейса сайта Stellar Burgers

### Реализованные сценарии

Созданы автотесты, покрывающие следующие пользовательские действия:

Личный кабинет:
- переход в личный кабинет из главного меню;
- переход в историю заказов;
- выход из аккаунта.

Восстановление пароля:
- открытие страницы восстановления;
- отправка запроса на восстановление;
- переключение видимости поля пароля.

Авторизация:
- вход в аккаунт по кнопке «Войти в аккаунт»;
- авторизация с валидными данными;
- проверка доступности кнопки оформления заказа после логина.

Главная страница:
- переход по вкладке «Конструктор»;
- переход в «Ленту заказов»;
- открытие и закрытие модального окна ингредиента;
- добавление ингредиента в заказ;
- оформление заказа и отображение модального окна подтверждения.

Лента заказов:
- открытие модального окна с деталями заказа;
- отображение заказов из истории;
- увеличение счётчика выполненных заказов;
- увеличение счётчика заказов за сегодня;
- отображение нового заказа в разделе «В работе».

### Структура проекта

- `tests` - пакет, содержащий тесты, разделенные по функциональности. Например, `test_user_login.py`, 
`test_create_order.py` и т.д.

- page_object — реализация паттерна Page Object (все страницы сайта)
- locators — локаторы для всех страниц
- tests — тестовые сценарии, сгруппированные по функциональности
- conftest.py — фикстуры, настройки и подготовка окружения
- urls.py — базовые URL-адреса проекта
- requirements.txt — зависимости

### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

**Запуск автотестов и создание Allure-отчета**

>  `$ pytest --alluredir=allure-results`
